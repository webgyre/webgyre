# Security reporting

This repository contains the WebGyre GitHub profile, documentation and public visual assets. It does not contain client applications, customer data or production credentials.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/webgyre/webgyre/security/advisories/new) for security issues in this repository. For an issue affecting webgyre.com, email [support@webgyre.com](mailto:support@webgyre.com) with the subject `Security report`.

Include the affected URL or file, the impact and a minimal reproduction. Redact credentials, personal information and customer data. Do not publish an exploit or secret in a public issue.

Do not access other people's accounts, download customer data or disrupt a service. This policy does not grant permission to test systems belonging to customers or third parties.

## Maintainer practices

- Keep account two-factor authentication enabled and recovery methods accessible.
- Use credentials stored in the operating system keyring; never commit passwords, tokens or recovery codes.
- Keep repository secret scanning and push protection enabled.
- Review public content and asset changes before publishing.
- Only introduce GitHub Actions workflows when needed, with minimal permissions and reviewed dependencies.

These are maintenance practices, not a claim that any account or system is immune to compromise.
